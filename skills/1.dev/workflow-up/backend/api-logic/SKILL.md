# API Logic 分析 Skill

## 前置检查

缺少以下任一项，必须先向用户索要，不得跳过：

- **业务描述**：这个模块是做什么的
- **后端技术架构**：框架（Laravel / Yii2 / Flask / Spring 等）、数据库、中间件

---

## 分析步骤

1. 扫描文件，列出全部接口（HTTP 方法 + 路由路径）
2. 调用 `business-logic` skill 提取接口逻辑
3. 汇总为统一文档

---

## 输出格式

~~~markdown
# {模块名} 接口文档

> {一句话说明模块业务用途}

---

## POST /api/xxx · 接口名称

**用途：** 简要说明业务目的

**流程：**
`business-logic` skill 分析出的流程
```

---

## GET /api/yyy · 接口名称

...
~~~

---

## 输出原则

- 按接口定义顺序输出
- 逻辑用业务语言描述，不贴源码
