## 第一步：诊断问题

拿到代码后，先快速扫描以下维度，找出主要问题：

| 维度 | 常见问题 |
|------|---------|
| **排版/间距** | padding/margin 不一致，元素拥挤或过散 |
| **字体** | 字号层级模糊，字重缺乏变化 |
| **组件状态** | 缺少 hover / active / disabled / loading 状态 |
| **动效** | 无过渡动画，或动画生硬 |
| **响应式** | 移动端布局断裂，元素溢出 |
| **反馈** | 操作后无视觉反馈（按钮点击、表单提交等） |

用 1-3 句话向用户说明发现的核心问题，然后开始修改。

## 第二步：优化原则

### 视觉美化
- **间距系统**：使用 4px 基数（8/12/16/24/32/48px），保持一致性
- **圆角**：统一圆角风格（要么全用大圆角 12-16px，要么全用小圆角 4-6px，别混用）
- **阴影**：层级感用阴影表达，卡片用柔和阴影（`box-shadow: 0 2px 12px rgba(0,0,0,0.08)`）
- **字体层级**：标题/正文/辅助文字 明确用不同字号+字重区分

### 交互优化
- **过渡动画**：所有状态变化加 `transition`，推荐 `0.2s ease` 起步
- **Hover 状态**：按钮、卡片、列表项必须有 hover 反馈
- **Loading 状态**：异步操作加 loading，用 `v-loading` 或骨架屏
- **空状态**：列表为空时显示友好提示，不要留白
- **操作反馈**：增删改操作后用 `ElMessage` 或动画给出明确反馈

### Vue3 特定技巧
```vue
<!-- 用 Transition 组件包裹条件渲染 -->
<Transition name="fade">
  <div v-if="show">内容</div>
</Transition>

<style scoped>
.fade-enter-active, .fade-leave-active {
  transition: opacity 0.2s ease;
}
.fade-enter-from, .fade-leave-to {
  opacity: 0;
}
</style>
```
