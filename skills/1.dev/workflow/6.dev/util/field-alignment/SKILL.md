---
name: field-alignment
description: 对齐两个数据表/类/接口之间的字段。当用户想比较两份数据结构（数据库表、JSON、类定义、API 响应等）的字段差异、做字段映射、或将一侧字段补充/同步到另一侧时触发。关键词：字段对齐、字段映射、字段对比、哪些字段缺失、同步字段。
---



## Step 1 — 解析输入

- 接受任意形式的数据结构描述：
  - 数据库 DDL / SHOW CREATE TABLE
  - JSON / JSON Schema
  - 类定义（Python dataclass、PHP class、Java POJO、TypeScript interface）
  - ClickHouse / MySQL 表结构
  - 自然语言描述
  - 代码片段
- 如果不知道 源头数据结构,目标数据结构, 请向用户提问。
- 若输入不完整，提示用户补充缺失的一侧。

---

## Step 2 — 输出三张对比表，请用户确认

### 相似或相同字段

| 源头字段 | 目标字段 | 类型是否一致 | 备注 |
|---------|---------|------------|------|
| id      | uid     | ❌ INT vs BIGINT | 描述 |

### 源头独有字段

| 字段 | 类型 | 备注 |
|------|------|------|

### 目标独有字段

| 字段 | 类型 | 备注 |
|------|------|------|

**输出后询问用户**：
> 表格是否准确？有无误判的相似字段或遗漏的对应关系？

---

## Step 3 — 确认对齐方向

用户确认表格后，询问：
1. **对齐范围**：仅补充独有字段 / 还是同步类型差异 / 全量覆盖？
2. **参考代码**：是否有现有的 Model / Migration / INSERT 模板？（有则按其风格生成）

---

## Step 4 — 生成对齐产物
- 若字段类型不一致（如 INT vs BIGINT），标注并询问用户采用哪侧类型。
