## 检查项

### 1. 文件存在性检查
- **检查内容**：docs/naming.md 文件是否存在
- **通过条件**：文件存在于 `docs/naming.md`
- **检查方式**：`bash test -f docs/naming.md`

### 2. 表格完整性检查
- **检查内容**：是否包含前缀表、词根表、后缀表三个表格
- **通过条件**：文件中存在 "前缀表"、"词根表"、"后缀表" 三个标题
- **检查方式**：读取文件内容，检查三个标题是否都存在

### 3. 格式正确性检查
- **检查内容**：三个表格是否为有效的 Markdown 表格格式
- **通过条件**：每个表格都有表头、分隔行和数据行
- **检查方式**：正则匹配表格格式 `^\|.*\|$`

### 4. 内容纯度检查
- **检查内容**：是否只包含三个表格，无多余内容
- **通过条件**：不包含额外的描述段落、章节标题（除三个表格标题外）
- **检查方式**：读取文件内容，排除表格后检查是否有多余段落

### 5. 表格内容非空检查
- **检查内容**：三个表格是否都有实际数据
- **通过条件**：每个表格至少有 2 行数据（不含表头）
- **检查方式**：统计每个表格的数据行数

## 输出报告格式

检查完成后，以如下格式汇报结果：

✅ 通过 / ❌ 失败 / ⚠️ 警告

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 文件生成 | ✅ | docs/naming.md 存在 |
| 表格完整性 | ✅ | 包含前缀表、词根表、后缀表 |
| 格式正确性 | ✅ | 三个表格格式正确 |
| 内容纯度 | ⚠️ | 包含额外描述内容 |
| 数据非空 | ✅ | 每个表格都有数据 |

**总结**：X 项通过，Y 项失败，Z 项警告。

## 失败处理
如果失败, 则重新执行name-dict(最多重复三次)
