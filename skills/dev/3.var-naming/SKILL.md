
## 命名规范

| 类型 | 规则 | 示例 |
|------|------|------|
| 项目/目录/文件 | 小写+中划线 | `my-project/` |
| 目录复数 | 复数命名 | `images/`, `components/` |
| 变量/方法 | 下划线 | `get_user_info()` |
| 常量 | 全大写下划线 | `MAX_COUNT` |
| 类/组件 | 大驼峰 | `UserCard` |

**禁止**：拼音、中文、无意义缩写、下划线起止


## Vue规范

### 组件
- 名称：**多个单词** + **PascalCase**（文件）
- 基础组件：`base-` 前缀
- 紧密耦合：父组件名作前缀

### Router
- 传参用**路由参数**（避免刷新丢失）
- 使用**路由懒加载**
- path：`kebab-case` + 以 `/` 开头
- name：`PascalCase` 且与组件名一致


## 实体和属性命名规范
- 下划线命名
- 每个命名由 多个前缀 + 多个词根 + 多个后缀拼接而成, 命名的格式为：`{前缀}_{词根}_{后缀}`
- 前缀, 词根, 后缀来自 `docs/naming.md`
  - 前缀: 前缀用于修饰,如: live_(直播的), video_(视频的), pre_(前置的)
  - 后缀: 后缀用于定性, 如: _cnt(统计), _inc(增量), _total(总量). _avg(平均值)
  - 词根: 词根用于描述, 如: user(用户), order(订单), product(产品)
