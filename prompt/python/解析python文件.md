## 参考示例
```
### 代码整体说明
该文件是电商订单系统的订单创建模块，负责接收用户下单请求，完成库存校验、订单生成和支付通知触发。

### 核心依赖库
1.  django：基于Django框架实现HTTP接口和ORM数据库操作
2.  redis：实现库存预扣的分布式锁，避免超卖
3.  requests：调用支付服务接口生成支付链接

### 核心类
1.  OrderCreateService
    - 核心职责：统一封装订单创建全流程逻辑
    - 核心方法：stock_check()（库存校验）、create_order_record()（生成订单记录）、send_pay_notify()（触发支付通知）

### 核心方法
1.  create_order(user_id, goods_list, address_id)
    - 入参：用户ID(user_id)、商品列表(goods_list)、收货地址ID(address_id)
    - 返回值：成功返回订单ID和支付链接，失败返回错误码和错误信息
    - 核心逻辑：先校验用户登录状态，再调用库存校验方法扣减库存，生成订单数据写入数据库，最后调用支付服务获取支付链接
    - 触发场景：用户在前端提交下单请求时触发
2.  stock_check(goods_list)
    - 入参：商品列表(goods_list，包含商品ID和购买数量)
    - 返回值：库存充足返回True，不足返回False和对应商品ID
    - 核心逻辑：基于redis分布式锁查询商品库存，库存足够则预扣对应数量，不足直接返回失败
    - 触发场景：订单创建流程中被create_order方法调用

### 次要方法
1.  check_user_login(user_id)：校验用户登录状态，被create_order方法调用
2.  get_user_address(address_id)：查询用户收货地址详情，被create_order方法调用
3.  format_order_data(order_info)：格式化订单数据为前端展示结构，被create_order方法调用

### 核心变量
1.  REDIS_LOCK_KEY：固定值为"order:stock:lock:{{goods_id}}"，库存锁的redis键名，全局生效
2.  ORDER_EXPIRE_TIME：固定值为1800（单位秒），订单未支付自动取消时长，全局生效
```
